OmniRemote 网页烧录器

一根 M5Stack StickS3 控全家空调。直接从浏览器把 OmniRemote 固件刷进去,普通用户不需要装 PlatformIO 或 esptool。烧完拔线就用,不需要联网、不需要账号。

  • 固件 v0.3.1
  • 目标 ESP32-S3
  • 写入地址 0x0
  • ~690 KB
请用桌面版 Chrome 或 Microsoft Edge 打开本页。 请通过 HTTPS 或 localhost 打开本页。

烧录完成后拔掉 USB,设备会用内置电池启动。如果屏幕不亮,双击侧边按键唤醒。

重刷固件默认不丢已配空调:点 Install 之后会弹"Erase device"复选框 + Back/Next。不勾直接 Next 就只重写 固件本身(bootloader / partitions / app 三段),NVS 区段不动,已配的 空调全部保留。需要彻底从零开始时再勾上 Erase。

使用步骤

  1. 电脑:用桌面版 Chrome 或 Microsoft Edge 打开本页。
  2. 硬件:用能传数据的 USB-C 线把 StickS3 连到电脑。
  3. 本页面:点上面"连接并烧录 OmniRemote"按钮,浏览器弹串口选择框时,选 StickS3 那个 USB CDC 设备。
  4. 硬件:烧完拔 USB,屏幕显示 OmniRemote v0.3 开机动画。
  5. 配对空调:把 StickS3 对准空调正面接收窗,长按正面大键 A(LCD 下方那个带蓝色装饰的)。SCAN 期间设备故意发"制冷 + 18°C + Max 风 + Turbo + Beep"刺激空调最响反应,听到"嘀"声立刻松手。
  6. 配对完会自动归位:松手后设备会再发一次默认 26°C/Auto 风,空调不会停在 18°C 狂吹状态。屏幕回 HOME。
  7. 多台空调:走到下一台,再来一次 — 就直接长按 A。不需要进菜单,长按 A 永远等于"配对新设备"。最多存 6 台。
  8. 日常用:A 短按 = 一键开关所有已配空调(toggle);HOME 大字"26"是下次广播的目标温度(setpoint),不是实测。B 短按滚菜单(温度±/模式/风速),B 长按执行该项并广播。

常见问题

  • 看不到串口:换一根能传数据的 USB-C 线(很多线只能充电),确认浏览器是桌面版 Chrome/Edge。
  • 配对扫了 90 秒没反应:你这台空调可能不在内置 75 个变体里。点 SCAN 时按 B 短按强制锁定当前正在试的码;或者去仓库提 issue 告诉我品牌型号。
  • 空调被打开了但屏幕没自动 FOUND:走得近一点(<1 m),或者听到响时 B 短按手动锁。
  • 命令行兜底:在装了 PlatformIO 的机器上 pio run -t upload -e m5sticks3-ac。
