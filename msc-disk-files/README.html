OmniRemote

一根 M5Stack StickS3 控全家空调 —— 这就是你手上插着的设备。

→ 打开烧录 / 配置页

用桌面版 Chrome 或 Microsoft Edge 打开上面的链接,把 USB-C 留着插着,网页就能 给这根 StickS3 烧录 / 升级固件。整个过程不联网设备本身、不需要装任何软件。

日常用法

  1. 长按正面大键 A — 配对新空调,听到"嘀"声立刻松手。
  2. A 短按 — 一键开关所有已配空调(toggle)。
  3. B 短按 滚菜单, B 长按 执行选项(温度/模式/风速)。
  4. 同时按住 A+B 三秒 — 清空所有 profile 重新开始。

源码 / 反馈

  • GitHub: github.com/openbrt/omniremote
  • 遇到空调撞库 90 秒还匹配不上,去 GitHub issue 报你空调的品牌和型号。

One M5Stack StickS3 controls every AC in your home — that's the device you have plugged in.

→ Open the flasher / config page

Open the link above in desktop Chrome or Microsoft Edge. Keep USB-C connected and the page can flash / update firmware on this StickS3 directly. The device itself never goes online, and you don't install anything on your computer.

Daily use

  1. Hold front big button A — pair a new AC. Release the moment you hear the beep.
  2. A short press — toggle every saved AC at once.
  3. B short scrolls the menu, B long runs the selected item (temp / mode / fan).
  4. Hold A+B for 3 s — factory reset, wipe every saved profile.

Source / feedback

  • GitHub: github.com/openbrt/omniremote
  • If SCAN runs the full 90 seconds without a match, file a GitHub issue with the AC's brand and model.
